# ReadO(1)

![Build](https://github.com/shibuzgeorge/readO1/actions/workflows/laravel.yml/badge.svg)

### Introduction
ReadO(1) is an innovative single page web application solution for computer science students promoting the
aspects of speed reading techniques. Students can browse through a variety of computer
science textbooks/texts and search through lists of categories and modules. Admins and
module tutors can upload PDFs of reading material to everyone (extensive reading sections) or
certain modules and create quizzes. Students have the ability to time themselves as they read
and tips of speed reading methods and techniques will be displayed. A quiz is required to be
answered at the end of the reading based on what they’ve read. Feedback will be given based
on the quiz attempted producing a score for each quiz they’ve taken and the time taken to read
the text with attempt numbers for all sessions.

The backend is written in Laravel framework, the frontend uses Vue.js.
